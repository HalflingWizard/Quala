How Quala works

Quala separates discovery, comparison, codebook change, application, and verification so each decision can be reviewed in the audit log.

1. Document Scout

Reads the document without seeing the codebook. Finds possible concepts and context-rich exact quotes.

2. Novelty Detector

Compares scout findings with the current codebook. Decides whether each concept is new, covered, or a possible merge.

3. Merge Reviewer

Reviews similar concepts and argues for and against merging before recommending a decision.

4. Codebook Update

Quala adds verified new codes or applies approved merges. Stable code IDs preserve links across documents.

5. Codebook Applier

Uses the updated active codebook on the same document. It can apply codes but cannot create them.

6. Evidence Auditor

Checks that every saved quote is an exact contiguous part of the source document. Only verified annotations are saved.

How the codebook grows

The Scout proposes evidence. The Novelty Detector compares it. The Merge Reviewer checks overlap. Quala updates the codebook before the Applier uses it.
